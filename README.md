# Team Server — единая система Host ⇄ Pi

Локальная система для работы двух машин в одной сети:

- **Host** — запускает сервер (веб-панель + консоль-хост), хранит файлы и журнал;
- **Pi** — подключается к Host, отправляет файлы и проекты, смотрит диаграммы, отслеживает работу.

Все модули связаны в одну систему: общее хранилище `data/files` и `data/projects`,
единая БД `data/team_server.db` (журнал действий виден и в консоли, и в веб-панели),
одни и те же генераторы диаграмм (`app_platform`) у веб-анализа и консоли.

## Структура

```
app_platform/          # веб-панель (FastAPI): загрузка, анализ, диаграммы, журнал, роли
getting_started/       # консоль Host ⇄ Pi: TCP-протокол, обмен файлами, диаграммы
gitdiagram-static/     # статический анализ кода → mermaid-диаграмма
data/                  # общее хранилище (files, projects, exports) + team_server.db
run_server.py          # точка входа веб-сервера
```

## Установка (обе машины)

Требуется Python 3.11+. В систему ничего не ставится — только виртуальное окружение:

```bash
cd Team_Server-main
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt -r requirements-dev.txt
```

## Запуск

### Host — сервер (веб-панель + хост консоли)

```bash
.venv/bin/python run_server.py
```

Сервер слушает `0.0.0.0:8000`. Откройте `http://<IP-хоста>:8000` в браузере —
это веб-панель: панель проектов, анализ репозитория, журнал действий, сайт gitingest.

Отдельно запускать консоль-хост не обязательно: веб-панель и консоль работают
на одном сервере и пишут в одну БД и одно хранилище.

### Pi (и Host) — консоль обмена файлами

```bash
.venv/bin/python getting_started/gettingstarted_linux.py
```

или через CLI пакета:

```bash
.venv/bin/gitdiagram-static connect
```

Консоль спросит режим (`host`/`pi`) и адрес хоста (по умолчанию порт `47823`;
для Pi — `--host <IP-хоста>`), далее команды: `upload` (файл или zip-проект),
`download`, `tree`, `analyze`, `journal`, `quit`. Загруженные проекты и файлы
появляются на веб-панели Host без дополнительных действий.

### Переменные окружения (необязательно)

| Переменная | Назначение |
|---|---|
| `TEAM_SERVER_DB` | путь к БД (по умолчанию `data/team_server.db`) |
| `GETTINGSTARTED_STORAGE` | базовый каталог хранения (по умолчанию `data/`) |

## Тесты

```bash
# сквозной e2e: связность всех модулей (15 проверок)
.venv/bin/python getting_started/tests/e2e_system.py

# веб-панель (6 проверок)
.venv/bin/python -m pytest tests/app_platform -q
```

## Роли

- **Host** — видит весь журнал, скачивает чужие экспорты (PNG/digest/API);
- **Pi** — видит в журнале только свои действия, работает со своими проектами.
