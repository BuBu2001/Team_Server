# cryless

Библиотека команд для Team Server, которая работает как git: связывает папку
вашего проекта с репозиторием на сервере (Host).

## Команды

```bash
cryless create repository [имя]   # создать репозиторий и зарегистрировать его на сервере
cryless load data [имя]           # загрузить данные (файлы проекта) в репозиторий
cryless connection check          # проверить, есть ли соединение с сервером
cryless help                      # справка по командам
cryless version                   # версия
```

## Условия

* команду запускают **в корне проекта** — там, где лежат его файлы;
* в имени проекта/репозитория **нет пробелов и нет кириллицы** — только
  латиница, цифры, точка, дефис, подчёркивание (`my_project`, `api-v2`, `site.ru`);
* если имя не указано, берётся имя текущей папки (оно тоже должно быть допустимым).

## Пример

```bash
cd ~/my_project
cryless create repository my_project
cryless load data
```

После `create repository` в корне проекта появляется каталог `.cryless/`
(настройки и токен доступа) и файл `.crylessignore` — список того, что не надо
отправлять на сервер (синтаксис как в `.gitignore`: `.venv/`, `__pycache__/`,
`*.log` и т. п.). Файлы больше 10 МБ пропускаются, архив целиком — до 256 МБ.

## Настройки

| Что | Как задать |
|---|---|
| адрес сервера | флаг `--server`, `CRYLESS_SERVER`, или `~/.config/cryless/config.json` |
| ник | флаг `--user`, `CRYLESS_USER`, или глобальный конфиг |
| каталог настроек | `CRYLESS_HOME` |

По умолчанию сервер — `http://localhost:8000` (запустите его на Host: `./run.sh`).
